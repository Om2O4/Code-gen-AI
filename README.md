# 🤖 Code-gen-AI

*A streamlined Artificial Intelligence tool for automated code generation, refactoring, and debugging.*

## 📖 Overview

**Code-gen-AI** is an intelligent assistant designed to accelerate the software development lifecycle. By leveraging advanced prompt engineering and Large Language Models (LLMs), this application translates natural language requirements into functional, optimized, and secure code. Whether you are generating boilerplate structures, writing complex SQL queries, or debugging object-oriented architecture, Code-gen-AI acts as a reliable pair-programmer.

## ✨ Key Features

* **Natural Language to Code:** Instantly convert plain English prompts into syntactically correct code snippets.
* **Intelligent Debugging:** Input broken code to receive automated error analysis and corrected output.
* **Context-Aware SQL Generation:** Generate complex relational database queries, schema definitions, and `JOIN` operations from simple text instructions.
* **Optimized Prompting System:** Built with highly refined system prompts to ensure the AI returns contextually accurate and highly optimized algorithms (e.g., targeting $O(N)$ time complexity).
